# Baristas — Café & Restaurante Premium

Sitio web desarrollado para un café y restaurante ficticio, creado como parte de mi **portafolio de desarrollo web**.

## 📌 Sobre el proyecto

Baristas es una página web diseñada para representar la presencia digital de un café y restaurante premium, con una identidad visual enfocada en la gastronomía, el café y una experiencia moderna.

El proyecto fue desarrollado para practicar la creación de interfaces web orientadas a negocios del sector gastronómico, trabajando la estructura, presentación de contenido y diseño visual desde cero.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## ✨ Características

* Diseño moderno y elegante
* Interfaz orientada al sector gastronómico
* Presentación visual de productos y platillos
* Secciones informativas del restaurante
* Diseño adaptable a diferentes tamaños de pantalla
* Estructura web organizada
* Desarrollo realizado desde cero
